## Styling
For style use basecoat library (its like shadcn but not require react based frameworks).
Every question you have about how use bosecoat search directly into the /basecoat-repo/ directory for view how implement

To get started with these components, you can install them individually using the CLI. For example, to add the Dialog component, run:

npx basecoat-cli add dialog
